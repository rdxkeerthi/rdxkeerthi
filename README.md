### 🛡️ About Me

I am a security engineer and systems builder focused on building robust defense mechanisms, telemetry pipelines, and security automation tooling. My work bridges low-level systems programming (Rust/C) with distributed detection engineering and cloud infrastructure resilience.

- 🚀 **Published Author:** Creator of [`kpay`](https://www.npmjs.com/package/@rdxkeerthi/kpay) on the npm registry.
- 🔭 **Active Engineering:** Architecting **SIEM-Plus** (a next-generation SIEM platform featuring a lightweight Rust endpoint agent, Sigma detection rules, and automated SOAR playbooks) and **NexisCore** (Zero-trust runtime sandbox).
- 🔬 **Current Research:** Post-quantum cryptography (PQC) readiness, TLS downgrade attack simulations, and kernel-space eBPF telemetry.
- 💬 **Ask Me About:** Security telemetry, log pipelines (Elastic/Splunk), malware sandboxing (Cuckoo), threat hunting, and systems automation.
