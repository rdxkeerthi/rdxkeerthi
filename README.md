### 🛡️ About Me

I am a security engineer and systems developer working across low-level internals (Rust, C), compiler/interpreter design, and high-performance package tooling. My engineering spans defensive detection infrastructure, malware sandboxing heuristics, and developer-first utility ecosystems.

- 🚀 **Package & Tooling Creator:** Author of [`@rdxkeerthi/kpay`](https://www.npmjs.com/package/@rdxkeerthi/kpay) on npm and [`fastflow`](https://pypi.org/) on PyPI.
- ⚙️ **Language Engineering:** Architect of **rdx-lang**, a custom language and runtime built from scratch focusing on minimal memory footprint, structured syntax, and native execution speed.
- 🔭 **Security Systems:** Developing **SIEM-Plus** (a distributed SIEM engine featuring a Rust telemetry collector, Sigma rule evaluation, and SOAR automation) and **NexisCore** (Zero-trust runtime sandbox).
- 🔬 **Research Areas:** Post-quantum cryptographic primitives (PQC), runtime isolation, eBPF telemetry, and resilient micro-frameworks.
- 💬 **Ask Me About:** Compiler design (ASTs/lexers/interpreters), async runtime execution, security telemetry pipelines (Elastic/Splunk), and binary analysis.

### 🔬 Featured Security & Systems Work

- **[rdx-lang](https://github.com/rdxkeerthi/rdx-lang):** Custom programming language toolchain containing lexing, AST parsing, and a high-performance interpreter runtime.
- **[fastflow](https://github.com/rdxkeerthi/fastflow):** Lightweight Python async pipeline and task engine designed for rapid execution with zero bloat.
- **[NexisCore](https://github.com/rdxkeerthi/NexisCore):** Zero-Trust execution sandbox with cryptographic attestation and runtime policy enforcement.
- **[Post-Quantum TLS Simulator](https://github.com/rdxkeerthi/Post-Quantum-TLS-Readiness-and-Downgrade-Attack-Simulator):** Cryptographic testbed assessing PQC algorithm migration and protocol downgrade attack vectors.
- **[Malware Analysis Platform](https://github.com/rdxkeerthi/Malware-analysis-App-analysis-tool):** Automated static/dynamic inspection engine delivering behavioral heuristics and automated IoC extraction.
- **[Cloud DDoS Detection](https://github.com/rdxkeerthi/DDoS-IBM):** High-volume anomaly detection and traffic mitigation pipeline designed for distributed networks.
